# 浙江品汇阀门有限公司 企业官网 — 开发规划

> 项目目录：`~/Desktop/浙江品汇阀门有限公司/pinhuivalve`
> 技术栈：Vue 3 + Vite + Vue Router 4（npm），无 UI 框架，手写设计系统
> 素材来源：`~/Desktop/浙江品汇阀门有限公司/素材`
> 参考版式：`素材/品汇阀门工业官网首页.png`

---

## 一、目标与原则

1. **以真实资料为准**：所有产品参数、尺寸表、材质、注意事项均来自
   `温州品汇阀门有限公司样本册单P(刀闸阀).pdf`（26 页，图文型 PDF，已逐页解析）；
   企业信息来自 `素材/官网介绍`；不使用任何编造数据（无邮箱、无成立年份、无认证证书的地方一律留空或不写）。
2. **工业官网气质**：深海军蓝 + 品牌蓝、白底大留白、细分割线、英文小字眉题，
   对齐参考图的区块节奏。
3. **产品详情是主体**：12 个产品页承载完整技术参数、材质表、外形连接尺寸表（含 PN 分组、
   DN 全规格），并支持表格横向滚动与分组表头。
4. **可维护**：所有内容集中在 `src/data/*.js`，改文案/参数无需碰组件。

## 四、设计系统

- 色彩：`--navy-900 #061B30`、`--navy-800 #0A2540`、`--blue-600 #1A5FA8`、
  `--blue-500 #1E6FBF`、`--ink #16222F`、`--muted #6A7A8A`、`--line #E2E8EF`、
  `--bg-soft #F5F7FA`、品牌红 `--brand-red #C8102E`（取自 logo）
- 字体：`PingFang SC / Microsoft YaHei / Noto Sans SC` 系统栈；标题 700，眉题英文 12px 加字距
- 容器 1240px，区块节奏 96/120px，卡片圆角 2px（工业感，不做大圆角）
- 交互：滚动进入淡入上移（IntersectionObserver）、导航吸顶、产品筛选、表格滚动提示、
  移动端抽屉菜单
